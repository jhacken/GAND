# GAND

This repository presents GAND (Gender-Ambiguous Natural Data), a benchmarking resource for evaluating gender in machine translation. Next to the dataset itself (included in the `GAND_data` directory), the repository also contains the programming scripts that were used to compile the dataset (`GAND_compilation` directory). All subdirectories contain a separate read me including more detailed information.
