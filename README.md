# GAND

This repository presents GAND (Gender-Ambiguous Natural Data), a benchmarking resource for evaluating gender in machine translation. Next to the dataset itself (included in the `GAND_data` directory), the repository also contains the programming scripts that were used to compile the dataset (`GAND_compilation` directory) and the scripts that were used to perform the interpretability analysis (`GAND_interpetabilityAnalysis`). Finally, any materials supplementing the papers written on the GAND dataset are included in the `supplementaryMaterials` directory. All directories contain a separate read me including more detailed information.
