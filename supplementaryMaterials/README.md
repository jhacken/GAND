# Supplementary materials

- `d_stats_filter_data_coreference_C4.json`: Python dictionary containing detailed statistics (overall and per referent) on the effect of the coreference filter applied during the data compilation process for the C4 dataset. For more information on the filter, please refer to `GAND_compilation`.
- `d_stats_filter_data_coreference_OpenSubtitles.json`: Python dictionary containing detailed statistics (overall and per referent) on the effect of the coreference filter applied during the data compilation process for the Open Subtitles dataset. For more information on the filter, please refer to `GAND_compilation`.
- `d_stats_filter_data_referentEntities_C4.json`: Python dictionary containing detailed statistics (overall and per referent) on the effect of the referent entity filter applied during the data compilation process for the C4 dataset. For more information on the filter, please refer to `GAND_compilation`.
- `d_stats_filter_data_referentEntities_OpenSubtitles.json`: Python dictionary containing detailed statistics (overall and per referent) on the effect of the referent entity filter applied during the data compilation process for the Open Subtitles dataset. For more information on the filter, please refer to `GAND_compilation`.
